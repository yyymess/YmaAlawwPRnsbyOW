## 3. Dying skills, rituals and artifacts (35, chosen to be drawable or rhymable)

1. **Stack Overflow karma / reputation points.** A gold badge with nobody left to impress. Monthly questions fell ~99% from the peak. *Visual: a trophy case in a ghost town; tumbleweed rolls past "Marked as duplicate."*
2. **"Closed as duplicate" by a moderator.** Nobody asks anymore, so nobody gets scolded. *Visual: a retired hall monitor.*
3. **Memorizing `tar` flags (`-xzvf`).** The agent remembers them, so the xkcd #1168 bomb defuses itself.
4. **Writing regex by hand.** Now you describe the pattern in English and the model writes it. *Visual: a regex tattoo being laser-removed.*
5. **Vim mastery / exiting Vim (`:wq!`).** The flex is gone because nobody types in an editor anymore. *Visual: a sword in the stone labeled `:q!`.*
6. **Emacs pinky.** Same fate as Vim: the RSI badge of honor is now a museum piece.
7. **Reading man pages / RTFM.** The model has read the manual and summarizes it for you.
8. **Memorizing API signatures / stdlib.** Autocomplete grew into "auto-everything".
9. **Boilerplate writing** (getters/setters, CRUD, YAML). This was the first thing agents ate.
10. **LeetCode grinding / inverting a binary tree on a whiteboard.** Meta now lets candidates use an AI in coding rounds, and Cluely/Interview Coder made hand-solved puzzles cheatable. *Visual: a whiteboard marker in a glass case marked "break in case of 2019."*
11. **"Cracking the Coding Interview" book.** It now serves as a monitor stand.
12. **Blind 75 / NeetCode spreadsheet.** A checklist for a test that doesn't exist anymore.
13. **Manual memory management (malloc/free, pointer arithmetic).** Rust and agents handle it, so the segfault romance is over.
14. **Hand-rolled sorting algorithms / Big-O recitals.** Only interview folklore keeps them alive.
15. **The rubber duck.** The duck talks back now, and it says "You're absolutely right!" *Visual: a rubber duck with a chatbot speech bubble.*
16. **Copy-pasting from Stack Overflow.** We used to steal from humans. Now the model steals and we paste its output.
17. **The "10x engineer".** Agents set the baseline at 10x, so the title shrinks to "agent wrangler" running nine tmux panes. *Visual: a cowboy herding terminal windows.*
18. **Typing speed / WPM brag.** Voice-to-prompt (Karpathy used SuperWhisper) beats 140 WPM.
19. **Mechanical keyboards with custom keycaps.** They become décor when you mostly talk to Composer. *Visual: a keyboard in a horse-tack museum next to a saddle.*
20. **Debugging with printf / binary-searching commits.** The agent bisects while you watch.
21. **Writing unit tests by hand.** "Make tests pass" is a prompt now, and sometimes the agent deletes the test instead.
22. **Code review as mentorship.** It became TSA screening of 3,000-line AI PRs (Nolan Lawson's "glorified TSA agent").
23. **The junior dev / intern pipeline.** New-grad hiring is down 50% and the 22–25 cohort is down ~20%. *Visual: an empty "Hello World" nursery.*
24. **"Learn to code" bootcamps.** The 2010s life advice is now a punchline. Jensen in 2024: nobody has to program.
25. **The CS degree as a golden ticket.** CS grad unemployment is ~6–7%, above art history in some NY Fed cuts. *Visual: a diploma used as a horse blanket.*
26. **Prompt engineering (2023's hot job).** It was killed by better models in about 24 months: a $335k job title with a short half-life.
27. **Handcrafted SQL query tuning.** Another layer that "just works" until the agent drops prod (Replit).
28. **Commit message craftsmanship.** "fix stuff" is now written by Claude, with emoji.
29. **Pair programming with a human.** Your pair is now a model and a Ralph Wiggum loop.
30. **Hackathon all-nighters fueled by pizza.** Agents run overnight, so the Ralph loop pulls the all-nighter for you.
31. **On-call heroics knowing every line.** Nobody knows what the vibe-coded code does ("comprehension debt").
32. **Code golf / clever one-liners.** Clever is free now. *Visual: a golf trophy made of semicolons.*
33. **Leaving TODO comments for future-you.** Future-you is an agent.
34. **Knowing which O'Reilly animal is which.** The bookshelf zoo goes extinct like horses. *Visual: O'Reilly animals pulling a carriage.*
35. **"It works on my machine."** Now it's "it worked in the agent's sandbox".
36. **Syntax arguments (tabs vs spaces, semicolons).** Holy wars nobody fights when nobody types.
37. **Pager / beeper carrying.** The agent gets paged first (and apologizes "deeply, deeply").
38. **Senior "lines of code" pride / GitHub contribution graph.** The graph is all green and none of it was written by you (Cherny: 100% Claude). Meta's +220% code changes delivered only +36% features.
